# Security Policy

## Supported versions

This project is currently in active development. Security updates are handled on the main branch and in the latest published state of the repository.

## Reporting a vulnerability

Please do not report security issues in public GitHub issues or discussions.

Instead, contact the maintainer through a private channel or use GitHub's security reporting feature if available for the repository.

Provide as much detail as possible, including:

- the affected component or endpoint
- steps to reproduce the issue
- affected versions or branch
- severity assessment and impact
- any suggested remediation

## Responsible disclosure

We ask researchers and contributors to allow a reasonable time for the security issue to be investigated and fixed before public disclosure.
